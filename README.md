# AI Code Reviewer (Firebase + Gemini)

A simple web app that reviews code using Gemini and returns actionable feedback for:

- bugs
- security issues
- performance improvements

The app uses:

- Firebase Hosting for the frontend
- Firebase Cloud Functions (v2 HTTPS) for backend logic
- Google Gemini API for analysis

## Project Structure

```text
.
|- firebase.json
|- firestore.indexes.json
|- firestore.rules
|- functions/
|  |- index.js
|  |- package.json
|- public/
|  |- index.html
```

## Prerequisites

- Node.js 24.x (matching `functions/package.json` engines)
- npm
- Firebase CLI (`npm install -g firebase-tools`)
- A Firebase project
- A Gemini API key

## 1. Install Dependencies

From the project root:

```bash
cd functions
npm install
```

## 2. Configure Gemini API Key

This project reads `GEMINI_API_KEY` as:

- a Firebase Secret in production
- an environment variable in local emulator mode

### Production secret

From project root:

```bash
firebase functions:secrets:set GEMINI_API_KEY
```

Then deploy functions.

### Local emulator secret

Set an environment variable before starting emulators.

PowerShell:

```powershell
$env:GEMINI_API_KEY="your_gemini_api_key"
firebase emulators:start
```

CMD:

```cmd
set GEMINI_API_KEY=your_gemini_api_key
firebase emulators:start
```

## 3. Run Locally

From project root:

```bash
firebase emulators:start
```

Open the local Hosting URL shown in terminal (commonly `http://127.0.0.1:5000`).

The UI in `public/index.html` sends a POST request to `/reviewCode`, which is rewritten to the `reviewCode` Cloud Function via `firebase.json`.

## 4. Deploy

Deploy Hosting and Functions:

```bash
firebase deploy
```

Or only functions:

```bash
cd functions
npm run deploy
```

## API Contract

### Endpoint

`POST /reviewCode`

### Request body

```json
{
	"code": "function add(a, b) { return a + b; }"
}
```

### Response

Plain text review generated by Gemini.

## Notes

- Do not commit real API keys to source control.
- `firestore.rules` is currently in temporary open/testing mode with an expiry date. If you use Firestore in production, lock rules down before expiry.
